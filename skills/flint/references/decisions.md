# Decide the next investment

The decision is about a named increment, not the entire imagined future.

| Decision | Use it when | Leave behind |
| --- | --- | --- |
| Proceed | Evidence and authority justify the next slice within its constraints | Scope, owner, gates, accepted evidence |
| Investigate | A consequential uncertainty can be tested responsibly | Question, methods, limit, stop condition, evidence |
| Rescope | The outcome matters but this approach does not fit | Smaller/different approach and revised constraints |
| Defer | Timing, capacity or dependencies are wrong | Trigger for revisiting; owner |
| Stop | The current proposal is not justified | Reasons, evidence and useful learning |

## Check both sides

Do not confuse "possible" with "worth doing." Do not confuse "already possible elsewhere" with "no value here."

Evaluate:

1. **Outcome:** who benefits, and what changes?
2. **Experience:** can people understand, navigate, review or act more effectively?
3. **Complement:** what does this add alongside existing tools?
4. **Continuity/fidelity:** does it preserve the work and the underlying system's real behavior?
5. **Feasibility:** supported interfaces, licenses, constraints and skills.
6. **Burden:** build cost, review cost, operations and maintenance.

A product need can be real while the proposed implementation is infeasible. An implementation can work while the benefit remains unproven.

## Hard constraints are not scores

A dependency that cannot legally be used, a forbidden data disclosure or an unaffordable fixed commitment is not averaged away by ten attractive features.

Distinguish an unverified blocker from a demonstrated one. "No supported API found in the sources reviewed" is not "no API exists." Name a bounded next search or recommend waiting, not private-interface reverse engineering by default.

## Correct the record

When new evidence changes the decision, preserve the source and say what changed. Do not quietly rewrite the original intent or defend an earlier answer because it sounds consistent.

Partial acceptance is not full acceptance. Completing the research may produce a Stop recommendation and still be successful work.
